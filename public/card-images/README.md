# Card Images

Эта папка содержит изображения карт, которые подгружаются локально (не с wiki).

## Как заполнить изображения

### Вариант 1: Автоматическая загрузка (рекомендуется)

```bash
cd public/card-images
python3 download-images.py
```

Скрипт скачает все 278 изображений с `lil-alchemist.fandom.com` и сохранит их сюда.
Если Python не установлен — установите с https://python.org.

### Вариант 2: Вручную

1. Откройте `MANIFEST.json` — там список всех карт и ожидаемых имён файлов
2. Для каждой карты найдите изображение на wiki:
   - Откройте `https://lil-alchemist.fandom.com/wiki/Имя_Карты`
   - Или через поиск: `https://lil-alchemist.fandom.com/wiki/Special:Search?query=Имя_Карты`
3. Сохраните изображение как `<FileName>.png` (имя файла из MANIFEST.json)

## Имена файлов

Имена файлов формируются из имени карты:
- Пробелы → `_` (например `Bear Owl` → `Bear_Owl.png`)
- `:` → `_` (например `Speed:Onyx` → `Speed_Onyx.png`)
- Только буквы, цифры, `_`, `-`, `.`

## Если изображение не найдено

Если файл отсутствует или не загружается, карта показывает буквенный
плейсхолдер (первая буква имени карты) с цветом редкости. Это нормально —
сайт работает и без изображений.

## После заполнения

Закоммитьте изображения в git:
```bash
git add public/card-images/*.png
git commit -m "Add card images"
git push
```

GitHub Pages автоматически обновится после пуша.
